# הבוקר הוולנסי · אסתריקה

דף נחיתה לאירוע "הבוקר הוולנסי" של עגלת הקפה אסתריקה:
שיעור יוגה → סדנת נשימות וטבילות באמבט קרח → ארוחת בוקר מפנקת.

## מבנה
- `index.html` — הדף (עברית, RTL)
- `assets/style.css` — עיצוב
- `assets/main.js` — אנימציות גלילה וטופס הרשמה → וואטסאפ
- `assets/images/` — תמונות מהאטרקציות

## הרצה
פתחו את `index.html` בדפדפן, או:
```bash
python3 -m http.server 8000
```

## מה כדאי לעדכן
- התאריך, השעות והמיקום המדויק (סקשן "פרטי המפגש")
